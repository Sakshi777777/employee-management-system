
# Employee Management System

A C++ console-based application designed to manage employee records efficiently.

## Overview

The Employee Management System provides basic employee record management functionality using C++ programming concepts.

## Features

- Add new employee records
- Generate employee IDs
- View all employee records
- Search employees by ID
- Update employee details
- Delete employee records
- Calculate annual salary
- Store records using file handling

## Technologies Used

- C++
- Object-Oriented Programming
- Structures and Functions
- File Handling
- Conditional Statements and Loops

## Project Structure

- `main.cpp` — Main application source code
- `README.md` — Project documentation
- `.gitignore` — Files excluded from version control

## How to Run

1. Download or clone this repository.
2. Open `main.cpp` in a C++ compiler or IDE.
3. Compile and run the program.
4. Follow the menu displayed in the console.

## Learning Objectives

This project demonstrates basic CRUD operations, data storage, searching, updating, deleting and record management using C++.
